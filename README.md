# Lumen — HackDelft 2026

> Financial intelligence for your Revolut data.

Upload a Revolut CSV export → transactions get auto-categorized → clean analytics dashboard.

Built for the **Revolut AI Challenge** at HackDelft 2026.

---

## Repo structure

```
lumen/      Next.js 14 app (frontend + API routes)
python/     Python categorization microservice (coming soon)
```

## Quick start

```bash
cd lumen
cp .env.local.example .env.local   # fill in Supabase keys
npm install
npm run dev
```

See [`lumen/README.md`](lumen/README.md) for full setup instructions.
